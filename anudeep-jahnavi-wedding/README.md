# Anudeep & Jahnavi — Wedding Invitation

This is a standalone responsive website. It needs no build step, framework, or server.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `anudeep-jahnavi-wedding`.
2. Upload **both** `index.html` and `hero-portrait.jpg` from this folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main**, folder **/(root)**, then save.
6. GitHub will display a public link, typically:
   `https://YOUR-USERNAME.github.io/anudeep-jahnavi-wedding/`

The site will work directly at that address. Updates usually appear within a few minutes after you commit new files.

## Editing details

All text, colours, event details, and map links are in `index.html`. Search for the existing wording and replace it. Keep the image file name as `hero-portrait.jpg`, or update both image references in `index.html`.
